# Arc Light Bureau

English translation of Arc Light Bureau 1.12.3 for Starsector 0.98a-RC8.

## Requirements

- LazyLib
- MagicLib
- GraphicsLib

## Installation

Copy the `ArcLightBureau` folder into Starsector's `mods` folder and enable **Arc Light Bureau** in the launcher.

## Source and build

The translated Java source is retained under `jars/src`. The distributable mod uses the validated prebuilt `jars/TraverserDesignBureau3.jar`.
